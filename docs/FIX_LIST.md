# Phase 13 Reproduction Log

Audit date: 2026-11-04 (local Asia/Calcutta)

## Reproduced findings before fixes

| Page | Control / flow | What happens now | Root cause | Fix |
|---|---|---|---|---|
| Auth | Register invalid address | API returns HTTP 422 and the UI displays `[object Object]`. Valid address registers and signs in. | `request()` stringifies FastAPI's validation `detail` array as an object; UI has no useful validation formatter. | Format structured validation details into readable field messages; cover API error rendering. |
| Reports | Initial report list | Three fictitious reports appear, including hardcoded March 2024 figures and download URLs that do not exist. | `DEFAULT_REPORTS` is treated as user report history. | Start with a real empty state; only list exports generated by backend during this session (backend persistence/listing if required). |
| Reports | Generate PDF/Markdown | Sends `active_session`; the endpoint silently compiles an empty report when session is missing. On export error, UI fabricates a report row. | Hardcoded invalid session; permissive API fallback; local fabricated success path. | Bind export to a selected real session/dashboard; backend rejects missing/foreign source; show errors and only add returned artifacts. |
| Reports | Preview | Markdown modal shows a fabricated `content_preview`; PDF has no preview action. | Preview data is hardcoded in the UI instead of fetching generated artifact bytes. | Fetch same authenticated artifact and display rendered Markdown/PDF preview. |
| Reports | Download | Creates a plain anchor without auth, points relative URLs to fixed `localhost:8000`, and cannot show errors/loading. | Download bypasses shared authenticated API client and assumes a host/port. | Authenticated fetch, validate content type/status, download via Blob with server filename. |
| Dataset | Delete Table | Deletes immediately without confirmation; endpoint drops DuckDB table but swallows errors and does not clean dependent data. | No confirmation UI; silent `except`; missing cascading cache/dashboard/report cleanup. | Keep explicit confirmation, delete safely, invalidate dependent persisted objects and upload storage. |
| Dataset | Preview rows | No dataset preview control or server-side paginated preview endpoint exists. | API exposes only profile metadata. | Add bounded offset/limit endpoint and connect existing preview affordance without changing page layout. |
| Dashboard | Initial / generate | API failure falls back to static fabricated KPIs/charts; backend tool starts from hardcoded figures and only uses a table literally named `sales`. No per-file/all-files scope. | Default widget data and fixed sales schema in tool; UI catches failure as success. | Query each selected table live, support explicit per-file and combined scopes, join only reliable edges, and surface errors. |
| Dashboard | Export PDF | Sends fictitious `dashboard_export`; success indicator appears even if backend export failed; no file is downloaded. | Export API result is ignored and failures are hidden. | Pass actual dashboard payload/source to report generation; fetch/download generated file and show real error. |
| Workspace | SQL/Pandas Run | Evidence drawer exposes copy only; no validated rerun endpoint or Run action exists. | Tool endpoints only run inside agent pipeline; code is display-only. | Add authenticated, read-only validated execution endpoint; bind Run to exact visible code and show result/error. |
| Agent | “what is in these files / explain each file” | Existing routing/planning assumes fixed sales examples; overview path does not guarantee live per-table counts/schema summaries. | No explicit live dataset-overview plan and output contract. | Add live overview execution and ground all named tables and counts in ledger. |
| Agent | Production with mock provider | Engine considers deterministic planner/narrator fallback when provider is mock; docker-compose explicitly selects mock in `APP_ENV=production`. | Mock is allowed as the fallback path without production refusal. | Refuse user questions in production when no real provider is available; emit visible error event. |
| Datasets | Data Health score without selection/data | Page renders fallback score `94` when the API has no score. | Presentation fallback is a fake business metric. | Render only API-computed score and handle absent score as unavailable. |

- Registered and signed in through the UI using a disposable audit account. Initial invalid-email submission produced backend `POST /api/v1/auth/register` HTTP 422; the browser rendered `[object Object]`. Retrying a valid email navigated to `/workspace`.
- Browser console check returned no warning/error entries at the point checked. Backend request log confirmed the 422 then successful registration/login/profile traffic. No frontend crash observed.
- Source/API inspection reproduces the remaining items above. Dataset file selection was not completed through the in-app browser control during initial reproduction; the existing automated Playwright upload flow and focused API tests will supply that evidence.
